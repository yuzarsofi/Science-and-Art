# 🚀 Final Project: AI Chat & Art Studio

This is the final submission for the Science and Art of AI course. It combines a text-based chatbot with a generative art model into a single web application.

## Features
1.  **Chat Mode:** Uses `google/flan-t5-base` to answer questions.
2.  **Art Mode:** Uses `stable-diffusion-v1-5` to generate images from text.
3.  **Filters:** Apply Grayscale, Blur, or Edge Detection to generated art.

## How to Run Locally
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
